🐱 **Funny Cats** - Ваш персональный гид в мире котиков!

Откройте для себя безграничный мир милых и пушистых созданий! 
Наше приложение - это настоящий рай для любителей кошек.

## 📥 Установка

[📲 **Скачать FunnyCats-v1.0.apk**](releases/FunnyCats-v1.0.apk)

### Инструкция по установке:
1. **Скачайте** APK файл по ссылке выше
2. **На Android устройстве** откройте скачанный файл
3. **Разрешите установку** из неизвестных источников
4. **Установите** приложение
5. **Наслаждайтесь** котиками! 🐾

## ⚠️ Важно!
- Требуется Android 6.0+
- Размер: ~8 MB
- Разрешения: Интернет (для загрузки фото)

🌟 **Основные возможности:**
- 📸 **Бесконечная лента** - Листайте самые adorable фото котиков
- 📚 **Каталог пород** - Более 60 пород с детальными описаниями  
- ❤️ **Избранное** - Сохраняйте лучшие фото и породы
- 📖 **История просмотров** - Вернитесь к понравившимся котикам
- 🎨 **Персонализация** - Темная тема и гибкие настройки
- 🔔 **Умные уведомления** - Не пропустите новых пушистиков

🐾 **Для кого наше приложение:**
- Владельцы кошек, ищущие информацию о породах
- Любители животных для снятия стресса  
- Будущие хозяева, выбирающие питомца
- Все, кто ценит милоту и умиление

📱 **Особенности:**
- Простой и интуитивный интерфейс
- Работает оффлайн (сохраненные данные)
- Оптимизировано для всех устройств
- Без навязчивой рекламы

Присоединяйтесь к сообществу любителей котиков!
